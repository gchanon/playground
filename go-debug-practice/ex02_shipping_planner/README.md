# ex02 — Shipping planner: ของหายไปจาก manifest

**ระดับความรุนแรง:** P1 · **คนแจ้ง:** Fulfilment partner (BKK-NORTH)

## อาการที่เจอ

ตั้งแต่เราเปิดค่า handling fee ต่อ manifest คลังสินค้าแจ้งของขาดมาเรื่อย ๆ
การจัด 7 รายการด้วย batch size เท่ากับ 3 ได้ออกมา 3 manifest แต่มี SKU
ของลูกค้า 2 ตัวที่ไม่โผล่ใน manifest ไหนเลย — แถมบรรทัด handling fee ยัง
ไปโผล่ที่ *บนสุด* ของ manifest ใบที่สอง แทนที่จะอยู่ล่างสุด

ยอดรวมในเอกสาร manifest สอดคล้องกันเองหมด ฝั่งการเงินเลยไม่จับได้
มีแต่คลังที่สังเกตเห็น เพราะเขาหยิบของตาม manifest แล้วของจริงถูกทิ้งไว้
บนชั้นวาง

ถ้าปิด handling fee (`includeFees = false`) ปัญหาจะหายไป ทีมเลยเดาว่าเป็น
ปัญหาการคำนวณค่าธรรมเนียม — ซึ่งไม่ใช่ ยอดค่าธรรมเนียมถูกต้องแล้ว

## สิ่งที่ควรจะเป็น

ทุกชิ้นใน picklist ต้องปรากฏใน manifest ที่สร้างขึ้นมา **ครั้งเดียวพอดี**
และการวางแผนจัดส่งต้องไม่ไปแก้ picklist ของคนเรียกใช้
