# ex01 — Order service: การจองสต็อกของคลังสินค้า

**ระดับความรุนแรง:** P1 · **คนแจ้ง:** ทีม Warehouse ops

## อาการที่เจอ

ออเดอร์ที่สร้างผ่าน checkout ปกติทำงานได้ดี แต่ออเดอร์ที่เข้ามาจากคิว
draft ของคลัง (พวกที่เราสร้างกลับขึ้นมาจาก JSON payload ที่เก็บไว้)
ทำให้ worker process ตายทันทีที่มีการจองสต็อกครั้งแรก

pod รีสตาร์ท message ถูกส่งซ้ำ แล้วก็ตายอีก — ออเดอร์ draft ใบเดียว
เลยทำให้คิวจองสต็อกค้างทั้งคิว ทาง ops บอกว่าเริ่มเป็นหลังจากเราปล่อย
ฟีเจอร์ "resume abandoned carts" ซึ่งเป็นตัวที่ทำให้มีคิว draft ขึ้นมา

## สิ่งที่ควรจะเป็น

การจองสต็อกบนออเดอร์ draft ต้องทำงานเหมือนกับการจองบนออเดอร์ที่สร้าง
ใน process ทุกประการ คือ จำนวนที่จองไว้เพิ่มขึ้น และ `Release` ทำให้
มันลดกลับลงมา
