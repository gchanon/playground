# ex05 — Shard metrics aggregator: ตัวเลขที่บวกกันไม่ลงตัว

**ระดับความรุนแรง:** P2 · **คนแจ้ง:** Data / BI

> แบบฝึกหัดข้อนี้อยู่ใน Go module ของตัวเอง ซึ่ง pin ไว้ที่ `go 1.21`
> ให้รันเทสต์จากข้างในโฟลเดอร์นี้

## อาการที่เจอ

dashboard รายชั่วโมง "orders per shard" ให้ค่าผิด และผิดไม่เหมือนกันในแต่ละชั่วโมง:

- ส่วนใหญ่รายงานมาแค่ 1–2 shard แทนที่จะครบทั้ง 6
- บางรอบได้จำนวน shard ครบ แต่ค่าที่ได้เป็นตัวเลขเดิมซ้ำ ๆ
- ประมาณ 1 ใน 20 รอบ ได้ครบทั้ง 6 ตัวถูกต้อง
- ยอดรวมรายวันน้อยกว่าผลบวกของตัวเลขราย shard ที่เราไล่ query เองทีละตัวเสมอ

ตอนแรก BI คิดว่า shard ล่ม — ซึ่งไม่ใช่ เพราะ query ตรงไปที่แต่ละ DSN ได้ค่าที่
ถูกต้องทุกครั้ง และไม่มี error ใน log ของ aggregator เลย แถม job ยังเสร็จเร็ว
อย่างน่าสงสัย: ~2ms ทั้งที่ query shard เดียวใช้เวลาประมาณ 1ms และมีตั้ง 6 shard

บางครั้ง job จะ panic แทน ด้วยข้อความ `fatal error: concurrent map read and
map write`

## สิ่งที่ควรจะเป็น

`Aggregate` ต้องคืนผลลัพธ์ shard ละ 1 รายการ พร้อมจำนวนของ shard นั้นเอง
ทุกครั้งที่รัน
