# ex06 — K ร้านที่ถูกสั่งบ่อยที่สุด (heap)

**เวลา:** 25 นาที · **ระดับ:** medium

## โจทย์

หน้าแรกของแอปอยากโชว์ "ร้านยอดฮิต K ร้าน" จาก log ออเดอร์ของวันนี้
log เป็นรายชื่อร้าน 1 บรรทัดต่อ 1 ออเดอร์

```go
func TopKRestaurants(orders []string, k int) []string
```

- เรียงจากถูกสั่ง**มากไปน้อย**
- ถ้าจำนวนเท่ากัน เรียงตาม**ชื่อ A → Z** เพื่อให้ผลเหมือนเดิมทุกครั้ง
- ถ้าร้านมีไม่ถึง k ร้าน คืนทุกร้าน
- `k == 0` หรือไม่มีออเดอร์ → คืน slice ว่าง

## ตัวอย่าง

| orders | k | ผลที่ถูก |
|---|---|---|
| `kfc mk kfc som mk kfc` | 2 | `kfc mk` |
| `zen bonchon zen bonchon aroi` | 2 | `bonchon zen` (เท่ากัน 2 ครั้ง เรียงชื่อ) |
| `a b c d d` | 3 | `d a b` |

## ข้อจำกัด

- ออเดอร์สูงสุดราว 1 ล้านบรรทัด ร้านไม่ซ้ำราว 100,000 ร้าน, k เล็ก (เช่น 10)
- **เป้าการฝึก:** ใช้ `container/heap` ให้ได้ O(n log k) เทสไม่ได้บังคับว่าต้องใช้ heap (`sort` ทั้งหมดก็ผ่าน) แต่ Go เขียน heap เงอะงะกว่าภาษาอื่น ถ้าไม่เคยลองเขียน จะติดตอนสัมภาษณ์
- เทสมี input ใหญ่ที่จับเวลา 3 วินาที

## รัน

```bash
go test ./ex06_top_restaurants/
```

## คำถามต่อยอดที่ interviewer มักถาม

1. เรียงทั้งหมดแล้วตัด k ตัวแรก ต่างจากใช้ heap ขนาด k ยังไง เมื่อไหร่แต่ละแบบคุ้มกว่า
2. ทำไม heap สำหรับหา "มากสุด k ตัว" ถึงใช้ **min**-heap
3. ถ้าออเดอร์ไหลเข้ามาตลอด และต้องอัปเดตอันดับทุกนาที จะออกแบบยังไง
4. ถ้าต้องนับข้าม server 20 เครื่อง แต่ละเครื่องมี top 10 ของตัวเอง เอา top 10 ของแต่ละเครื่องมารวมกันแล้วได้คำตอบที่ถูกไหม
