# ex05 — เส้นทางสั้นสุดของไรเดอร์ในแผนที่ตาราง (BFS)

**เวลา:** 25 นาที · **ระดับ:** medium

## โจทย์

แผนที่ย่านหนึ่งถูกแบ่งเป็นตาราง ไรเดอร์เดินได้ทีละช่อง ขึ้น ลง ซ้าย ขวา (ไม่มีแนวทแยง)

| ตัวอักษร | ความหมาย |
|---|---|
| `S` | จุดที่ไรเดอร์อยู่ (มี 1 จุดเสมอ) |
| `E` | ร้านอาหาร (มี 1 จุดเสมอ) |
| `.` | ถนน เดินผ่านได้ |
| `#` | ตึก เดินผ่านไม่ได้ |

หาจำนวนก้าว**น้อยที่สุด**จาก `S` ไป `E` ถ้าไปไม่ถึงให้คืน `-1`

```go
func ShortestPath(grid []string) int
```

## ตัวอย่าง

```
S.#.
..#E      →  6
....
```

## ข้อจำกัด

- ตารางใหญ่สุด 1000 × 1000 และทุกแถวยาวเท่ากัน
- **เป้า:** O(แถว × คอลัมน์) เทสมีตาราง 1000 × 1000 ที่จับเวลา 3 วินาที

## รัน

```bash
go test ./ex05_rider_path/
```

## คำถามต่อยอดที่ interviewer มักถาม

1. ถ้าอยากได้**เส้นทาง**ด้วย ไม่ใช่แค่จำนวนก้าว ต้องเก็บอะไรเพิ่ม
2. ถ้าแต่ละช่องใช้เวลาเดินไม่เท่ากัน (รถติด = 5 นาที, ถนนโล่ง = 1 นาที) ยังใช้วิธีเดิมได้ไหม
3. ถ้ามีร้าน `E` หลายร้าน แล้วอยากรู้ว่าร้านไหนใกล้สุด ต้องรันหลายรอบไหม
4. ถ้ามีไรเดอร์ 1,000 คนกับร้าน 1 ร้าน อยากรู้ว่าไรเดอร์คนไหนใกล้ร้านสุด จะเริ่มค้นจากฝั่งไหน
