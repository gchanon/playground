## ซ้อมยังไงให้เหมือนห้องสัมภาษณ์

ในห้องจริง **การพูดคือครึ่งหนึ่งของคะแนน** ซ้อมพูดออกเสียงทุกข้อ ตาม 5 ขั้นนี้

| ขั้น | ทำอะไร | ประโยคตัวอย่าง |
|---|---|---|
| 1. ถามให้ชัด | input ใหญ่แค่ไหน, ว่างได้ไหม, ซ้ำได้ไหม, ติดลบได้ไหม | "ถ้าไม่มีคู่ไหนเลย ให้คืนอะไรครับ" |
| 2. วิธีตรงๆ | บอกวิธีง่ายสุดพร้อม complexity **ก่อน**เริ่มคิดวิธีเก่ง | "วิธีตรงๆ คือลองทุกคู่ O(n²)" |
| 3. วิธีที่ดีกว่า | บอกว่าจะใช้โครงสร้างอะไร ทำไม และได้ complexity เท่าไหร่ | "ใช้ map จำของที่เห็นแล้ว เหลือ O(n)" |
| 4. เขียน | ตั้งชื่อตัวแปรให้อ่านรู้เรื่อง พูดไปเขียนไป | |
| 5. ทดสอบด้วยมือ | ไล่ตัวอย่างเล็กๆ 1 ตัว แล้วไล่ edge case: ว่าง, ตัวเดียว, ซ้ำทั้งหมด | "ลอง `[50]` budget 100 ต้องได้ false" |

- จับเวลาตามตาราง ถ้าติดเกินเวลาให้เปิดเฉลย การนั่งเงียบนานๆ ในห้องจริงแย่กว่าการขอ hint
- ทำเสร็จแล้วตอบ "คำถามต่อยอด" ท้าย README ของแต่ละข้อด้วย ระดับ senior มักโดนถามต่อแบบนี้
